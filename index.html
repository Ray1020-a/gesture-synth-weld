📖 什麼是數實資研社附設資音組樂器？

數實資研社附設資音組樂器是一款在瀏覽器中執行的手勢合成器。它透過網路攝影機與 MediaPipe 手部追蹤，打造出一把雙手樂器 — 左手控制和聲（調性、音級、大小調切換）， 右手控制表情（和弦類型、音量、音色與八度）。不用下載、不需 MIDI 控制器、也不用裝外掛。

共有 3 種模式：手勢（雙手和弦演奏）、特雷門（連續控制音高與音量）、 單音鋼琴（單音旋律）。開啟琶音可以像豎琴一樣逐音撥奏和弦， 開啟自動低音則會跟著和聲自動補上低音。 最長可錄製 120 秒的演奏 — 音訊、完整影片，或保護隱私的骨架動畫 — 可直接下載或分享到社群平台。

聲音由 Tone.js（Web Audio API）低延遲合成，手指追蹤則由 MediaPipe Hands 即時處理（30fps）。 所有運算都在你的裝置本機進行 — 相機畫面絕不會上傳到任何伺服器。

你需要準備：一台有網路攝影機的電腦、新版瀏覽器（建議 Chrome、Edge 或 Firefox）， 以及喇叭或耳機。想要最佳體驗，請使用開啟 WebGL2 硬體加速的 Chrome 或 Edge。

🎛 手勢合成器能做什麼？

手勢合成器把肢體動作轉換成聲音。瀏覽器版的手勢合成器用網路攝影機追蹤你的雙手 — 不需要任何硬體控制器。 這把樂器更進一步：每根手指都是一個音樂指令，左手選和聲、右手塑造表情，全部在瀏覽器中即時運作，完全免安裝。

相較之下，硬體手勢合成器（感應手套、戒指感測器、MIDI 特雷門）雖然強大，但動輒數千元、還需要設定。 網路攝影機手勢合成器則免費提供相同的體驗 — 只要雙手在畫面內就行。這就是取捨：零硬體成本，只靠你的雙手。

💡 運作方式

1

允許相機

點「開啟相機」並允許相機權限。影像只留在你的裝置上 — 不會上傳任何東西。

2

左手 → 和聲

選擇調性（C–B，預設 A）。1–5 指選擇音級 I–V。食指＋小指 = VI，再加拇指 = VII。預設鎖定大調 — 在設定中切換到「音階 + 傾斜」即可用手腕傾斜控制大小調。

3

右手 → 表情

手指數決定和弦複雜度（1 = 三和弦、2 = 轉位、3 = 七和弦、4 = 九和弦）。高度 = 音量，傾斜 = 音色。需要雙手才會發聲 — 左手握拳靜音，右手握拳恢復原八度。也可以鎖定和弦風格。

🎹 演奏技巧

新手入門：最簡單的設定

預設設定可以立刻開始演奏：調性 = A 大調、 左手 = 只用音階（鎖定大調）、 右手 = 固定和弦風格（大三和弦）。 琶音與自動低音預設關閉 — 打開它們聲音會更豐富。只要舉起雙手 — 左手選音級，右手觸發和弦。

玩轉琶音

開啟琶音，把整塊和弦變成流動的分解和弦。和弦中的每個音會由低到高依序彈出（像豎琴一樣）。 慢速適合氛圍鋪底，一般適合旋律伴奏，快速適合熱力奔放的音群。 琶音適用於所有和弦類型與設定。

用自動低音讓聲音更飽滿

開啟自動低音，就會自動跟著左手和聲補上低頻。低音會在較低八度彈奏目前和弦的根音， 讓你的演奏有完整樂團的感覺。低音音量可獨立調整 — 輕輕的當背景襯底，或開大做出推進感。 自動低音和預設的手勢模式特別搭。 更多請看常見問題 →

探索固定和弦模式

把右手切換到固定和弦風格，就能鎖定特定的和弦類型。很適合專門練習某種和弦性質 （試試減三和弦或 Sus4，聽聽獨特的質感），或想專注在表情、不想管手指數的時候。 右手仍然可以控制音量、音色與八度 — 只有和弦類型被鎖定。

嘗試不同模式與效果

三種模式都試試看：手勢模式彈完整的雙手和弦、特雷門模式做有表情的滑音、鋼琴模式彈單音旋律。 把琶音和自動低音一起開，聲音會更有層次。用右手腕傾斜掃動濾波 — 左傾更暗沉、右傾更明亮。 把喜歡的演奏錄下來 — 音訊、完整影片或骨架動畫 — 分享出去或之後再回味。

錄製與分享

點紅色的錄製按鈕，最長可錄 120 秒的演奏。開始前有 3-2-1 倒數，結束前也有 3-2-1 收尾提醒。 選擇模式：只錄音訊、完整影片（相機畫面 + 手部骨架），或完全不顯示相機畫面的骨架動畫 — 再依分享平台選擇畫面比例（9:16 適合 TikTok／Reels／Shorts、16:9 適合 YouTube、1:1 適合 Instagram）。 想邊彈邊唱？麥克風會把你的聲音混進錄音，讓你用即時和弦替自己伴奏。 手機上可以直接從分享選單分享；電腦上則會下載成 MP4／M4A 或 WebM 檔。 音訊檔附有品牌封面與網址。你的相機畫面絕不會上傳到任何伺服器。 還有問題？看看常見問題 →

🔧 疑難排解 — 逐步說明

偵測不到相機（「找不到相機」）

💻 Windows（Chrome / Edge）

  1. 確認網路攝影機已插好、線材沒有損壞
  2. 關閉其他正在使用相機的 App（Zoom、Teams、Meet）— 相機一次只能被一個 App 使用
  3. 開啟 Windows 設定 → 隱私權與安全性 → 相機，確認「相機存取」為開啟
  4. 在同一頁確認你的瀏覽器（Chrome／Edge）有在清單中且已允許
  5. 回到這裡，再點一次開啟相機

🍎 Mac（Safari / Chrome）

  1. 確認網路攝影機已連接（且內建鏡頭沒有被遮住）
  2. 關閉其他正在使用相機的 App（FaceTime、Zoom）
  3. 開啟系統設定 → 隱私權與安全性 → 相機，確認你的瀏覽器已勾選
  4. 回到這裡，再點一次開啟相機

📱 iPhone / iPad（Safari）

  1. 開啟裝置的設定 → 隱私權與安全性 → 相機
  2. 確認清單中的 Safari 已開啟
  3. 回到瀏覽器重新整理頁面，再點一次開啟相機

🤖 Android（Chrome）

  1. 開啟設定 → 應用程式 → Chrome → 權限
  2. 確認相機設為允許
  3. 回到這裡重新整理頁面，再點一次開啟相機

相機權限被拒絕

你之前可能封鎖了這個網站的相機權限。依瀏覽器重新允許：

  • Chrome / Edge：點網址列的 🔒（或 ⓘ）圖示 → 相機 → 允許 → 重新整理 → 再試一次
  • Safari（Mac）：點網址列的相機圖示（或 Safari → 設定 → 網站 → 相機）→ 允許
  • Safari（iPhone/iPad）：設定 → 隱私權與安全性 → 相機 → 開啟 Safari，然後重新整理
  • Firefox：點網址列的 🧩 拼圖圖示 → 權限 → 相機 → 允許

接著重新整理頁面，再點一次「開啟相機」。

模型載入很慢或失敗

手部追蹤模型（約 20 MB）會在第一次使用時下載 — 網路較慢時可能需要幾分鐘。 進度條會持續前進；你可以取消，下載仍會在背景繼續（下次點擊就能立刻開始）。 如果載入失敗，請檢查網路連線並點重試。

手部追蹤卡頓或不準

手部追蹤透過 WebGL 使用你的 GPU。請關閉其他吃 GPU 的程式（遊戲、影片剪輯軟體）。 筆電請接上電源 — 有些瀏覽器在使用電池時會限制 GPU 效能。一般來說 Chrome 和 Edge 的 MediaPipe 效能最好。

沒有聲音

瀏覽器的自動播放政策規定，音訊引擎需要使用者操作才能啟動。請確認你已經點過「開啟相機」。 也請檢查瀏覽器沒有被靜音、系統音量有打開。另外請確認雙手都在相機畫面中 — 必須同時偵測到雙手且至少伸出一根手指才會發聲。

什麼是手勢合成器？

手勢合成器（gesture synth）是一種把網路攝影機拍到的手部動作轉換成音樂的工具 — 不需要任何實體樂器。 數實資研社附設資音組樂器就是在瀏覽器中執行的手勢合成器，把每根手指對應到不同的音， 讓你只要在空中揮動雙手就能演奏音樂。什麼是手勢合成器？ →

需要任何特殊設備嗎？

不需要。只要一台有內建或 USB 網路攝影機的電腦，以及 Chrome、Edge 或 Firefox 等新版瀏覽器。 不需 MIDI 控制器、外接感測器，也不用下載。所有輸入都來自你的攝影機 — MediaPipe 手部追蹤模型完全在你的裝置上執行。 用手機？不用安裝 App — 網址就是 App →

支援哪些瀏覽器？

支援 Web Audio API 與 getUserMedia 的新版瀏覽器都能使用 — 包括 Chrome 90+、Firefox 90+、Edge 90+ 與 Safari 15+。 想要最好的手部追蹤體驗，建議使用 Chrome 或 Edge，它們對 MediaPipe 的 WebGL2 後端支援最有效率。

可以錄下我的演奏嗎？

可以！點錄製按鈕開始錄下你的演奏（最長 120 秒）。 開始前有 3-2-1 倒數，結束前也有 3-2-1 收尾提醒。 選擇要錄的內容：只錄音訊、完整影片（相機畫面 + 手部骨架）， 或骨架動畫（不含相機畫面 — 保護隱私）。再依分享平台選擇畫面比例： 9:16 適合 TikTok／Reels／Shorts、16:9 適合 YouTube、1:1 適合 Instagram。 想邊彈邊唱？麥克風會混進錄音（可開關）— 很適合替自己的歌聲伴奏。 需要的話可在選單中挑選麥克風（有些 Mac 預設會用到錄不到聲音的虛擬裝置）， 並用錄音混音滑桿調整人聲與和弦的平衡 — 戴耳機的混音效果最乾淨。 錄完後下載檔案 — 或在手機上直接從分享選單分享到你的 App（分享訊息會附上品牌與 gesturesynthweld.com）。 你的相機畫面絕不會上傳到任何伺服器。 更多錄製技巧 →

可以彈哪些和弦？

支援全部 12 個調（C 到 B）以及兩種右手模式。 手指排列模式：1 指 = 三和弦、2 指 = 第一轉位、3 指 = 七和弦、4 指 = 九和弦。 固定和弦模式可從 8 種和弦類型中選擇：大三和弦、大三和弦第一轉位、小三和弦、減三和弦、 Sus2、Sus4、大七和弦與屬七和弦。可以鎖定在大調或小調，或在設定中開啟「音階 + 傾斜」， 用左手腕傾斜切換大小調。查看完整手勢表 →

沒有相機也能玩嗎？

可以 — 鍵盤模式把實體鍵盤變成樂器（僅限桌機，不需相機權限也不用下載模型）。 在設定 →「沒有相機？用鍵盤模式」開啟，或點上方工具列的 ⌨ 鍵盤按鈕 （在鍵盤模式下會變成 📷 相機 — 點一下就切回手勢），接著按 1-7 演奏音級 I-VII（按住發聲、放開停止）、[ / ] 切換小調／大調、 8/9/0/- 切換和弦風格、Shift 降八度、 ↑/↓ 調整音量、←/→ 掃動濾波，空白鍵停止。 第一次使用時會有附示範動畫的實體鍵盤教學 — 之後隨時可從 ? 說明面板重播。 鍵盤模式的錄製只錄音訊（可用麥克風加入你的聲音）— 影片模式需要相機畫面，所以在這裡會隱藏。

這把樂器和其他手勢合成器有什麼不同？

它採用獨特的雙手分工系統：左手控制和聲（選調、音級、大小調切換）， 右手控制表情（和弦複雜度、音量、音色、八度）。和一般的手勢合成器不同，它內建可做出豎琴般掃弦的琶音、 提供低頻基礎的自動低音、可即時掃動濾波的鋸齒波合成引擎， 支援九和弦（4 指）、8 種固定和弦風格，以及內建的 MP4/M4A 錄製。 它也是以 MIT 授權釋出的開放原始碼專案。
