關於數實資研社附設資音組樂器

數實資研社附設資音組樂器是一款開放原始碼、在瀏覽器中執行的手勢合成器。左手控制和聲（調性／音級／大小調），右手控制表情（和弦風格／音量／音色／八度）。不用下載、不用外掛、不用帳號 — 只要你的網路攝影機（或鍵盤模式）和雙手。

開放原始碼

以 MIT 授權釋出。原始碼、問題回報與貢獻：github.com/rainbow686/gesture-synth-weld。歡迎發 PR — 貢獻說明請見儲存庫。經費來源是選擇性且透明的：只有在首屏下方放置不干擾的廣告（如有）來支付主機費用；演奏與錄製都沒有付費牆。

技術

Vite + React + TypeScript，以 Tone.js（Web Audio）合成聲音，MediaPipe Tasks Vision（HandLandmarker）追蹤手部。網頁應用部署在 Vercel；手部模型放在 Cloudflare。所有運算都在本機進行 — 相機畫面絕不會離開你的裝置。
