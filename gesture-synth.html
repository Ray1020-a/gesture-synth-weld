🔍 什麼是手勢合成器？

手勢合成器（完整說法是手部手勢合成器）用動作取代鍵盤。 你不需要按鍵，而是在空中移動雙手：感測器 — 網路攝影機、深度攝影機或感應手套 — 讀取你雙手與手指的位置， 再由軟體把動作對應到音高、音量、音色等音樂參數。舉起手，音量變大；張開手指，和弦跟著展開。

數實資研社附設資音組樂器是一款瀏覽器手勢合成器，採用固定的雙手分工： 左手選和聲（手指數選擇音級 I–VII，手腕傾斜選大調或小調）， 右手塑造表情（高度是音量、傾斜是音色、手指數決定和弦厚度）。 不用安裝、不用花錢 — 只要你的裝置有攝影機，上方的樂器就已經是你的了。 完整手勢教學列出了每個動作。

🎛 手勢合成器能做什麼？

手勢合成器把肢體動作轉換成聲音。瀏覽器版的手勢合成器用網路攝影機追蹤你的雙手 — 不需要任何硬體控制器。 這把樂器更進一步：每根手指都是一個音樂指令，左手選和聲、右手塑造表情，全部在瀏覽器中即時運作，完全免安裝。

相較之下，硬體手勢合成器（感應手套、戒指感測器、MIDI 特雷門）雖然強大，但動輒數千元、還需要設定。 網路攝影機手勢合成器則免費提供相同的體驗 — 只要雙手在畫面內就行。這就是取捨：零硬體成本，只靠你的雙手。

⚡ 怎麼玩 — 30 秒彈出第一個和弦

1

允許相機

按上方的播放，允許相機權限。追蹤在你的裝置上執行 — 影像絕不會上傳。

2

左手 → 和聲

選擇調性（C–B，預設 A）。1–5 指選擇音級 I–V。食指＋小指 = VI，再加拇指 = VII。預設鎖定大調 — 在設定中切換到「音階 + 傾斜」即可用手腕傾斜控制大小調。

3

右手 → 表情

手指數決定和弦複雜度（1 = 三和弦、2 = 轉位、3 = 七和弦、4 = 九和弦）。高度 = 音量，傾斜 = 音色。需要雙手才會發聲 — 左手握拳靜音，右手握拳恢復原八度。完整對照：手勢教學 →

4

錄製與分享

每次最長 120 秒 — 音訊、完整影片或骨架動畫 — 然後下載或分享。

什麼是手勢合成器？

手勢合成器是一種用手部或肢體手勢、而非按鍵來演奏的樂器：感測器讀取你的動作，軟體把它變成聲音。 數實資研社附設資音組樂器是一款免費的瀏覽器手勢合成器 — 就是本頁最上方的那把樂器。 打開攝影機、舉起雙手、音樂就出來了。

這個頁面就是線上版本 — 不需要安裝 App。在上方的瀏覽器中直接演奏：允許相機就能開始。 這正是瀏覽器手勢合成器的重點：網址就是 App。 完整說明：為什麼沒有 App →

需要任何特殊設備嗎？

不需要。只要一台有內建或 USB 網路攝影機的電腦，以及 Chrome、Edge 或 Firefox 等新版瀏覽器。 不需 MIDI 控制器、外接感測器，也不用下載。所有輸入都來自你的攝影機 — MediaPipe 手部追蹤模型完全在你的裝置上執行。

支援哪些瀏覽器？

支援 Web Audio API 與 getUserMedia 的新版瀏覽器都能使用 — 包括 Chrome 90+、Firefox 90+、Edge 90+ 與 Safari 15+。 想要最好的手部追蹤體驗，建議使用 Chrome 或 Edge，它們對 MediaPipe 的 WebGL2 後端支援最有效率。

可以錄下我的演奏嗎？

可以！點錄製按鈕開始錄下你的演奏（最長 120 秒）。 開始前有 3-2-1 倒數，結束前也有 3-2-1 收尾提醒。 選擇要錄的內容：只錄音訊、完整影片（相機畫面 + 手部骨架）， 或骨架動畫（不含相機畫面 — 保護隱私）。再依分享平台選擇畫面比例： 9:16 適合 TikTok／Reels／Shorts、16:9 適合 YouTube、1:1 適合 Instagram。 想邊彈邊唱？麥克風會混進錄音（可開關）— 很適合替自己的歌聲伴奏。 需要的話可在選單中挑選麥克風（有些 Mac 預設會用到錄不到聲音的虛擬裝置）， 並用錄音混音滑桿調整人聲與和弦的平衡 — 戴耳機的混音效果最乾淨。 錄完後下載檔案 — 或在手機上直接從分享選單分享到你的 App（分享訊息會附上品牌與 gesturesynthweld.com）。 你的相機畫面絕不會上傳到任何伺服器。

可以彈哪些和弦？

支援全部 12 個調（C 到 B）以及兩種右手模式。 手指排列模式：1 指 = 三和弦、2 指 = 第一轉位、3 指 = 七和弦、4 指 = 九和弦。 固定和弦模式可從 8 種和弦類型中選擇：大三和弦、大三和弦第一轉位、小三和弦、減三和弦、 Sus2、Sus4、大七和弦與屬七和弦。可以鎖定在大調或小調，或在設定中開啟「音階 + 傾斜」， 用左手腕傾斜切換大小調。請看完整手勢表 →

沒有相機也能玩嗎？

可以 — 鍵盤模式把實體鍵盤變成樂器（僅限桌機，不需相機權限也不用下載模型）。 在設定 →「沒有相機？用鍵盤模式」開啟，或點上方工具列的 ⌨ 鍵盤按鈕 （在鍵盤模式下會變成 📷 相機 — 點一下就切回手勢），接著按 1-7 演奏音級 I-VII（按住發聲、放開停止）、[ / ] 切換小調／大調、 8/9/0/- 切換和弦風格、Shift 降八度、 ↑/↓ 調整音量、←/→ 掃動濾波，空白鍵停止。 第一次使用時會有附示範動畫的實體鍵盤教學 — 之後隨時可從 ? 說明面板重播。 鍵盤模式的錄製只錄音訊（可用麥克風加入你的聲音）— 影片模式需要相機畫面，所以在這裡會隱藏。

這把樂器和其他手勢合成器有什麼不同？

它採用獨特的雙手分工系統：左手控制和聲（選調、音級、大小調切換）， 右手控制表情（和弦複雜度、音量、音色、八度）。和一般的手勢合成器不同，它內建可做出豎琴般掃弦的琶音、 提供低頻基礎的自動低音、可即時掃動濾波的鋸齒波合成引擎， 支援九和弦（4 指）、8 種固定和弦風格，以及內建的 MP4/M4A 錄製。 它也是以 MIT 授權釋出的開放原始碼專案。
